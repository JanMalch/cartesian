Cartesian

For when people keep asking if you have thought of all possibilities. Enter any arbitrary amount of inputs below, together with their set of possible values. The table will show all unique combinations, giving you the option to describe and reason about them. Finally, you can share the table via a share link or copy its markup.

Made with 🧠 on GitHub.

Inputs

The values for each input can be any kind of text and are not interpreted, so true and false are just examples. Consider describing the equivalence classes of your problem domain. For example, when it comes to an input describing a list, you may use empty list, 1 item, and 2 or more items as values.

Extras

Define extra columns to show in the table. The format will only be visible in the final markup.

Results

This table shows all the possible combinations allowing you to describe each outcome. Anything you enter will be memorized by the exact input label as well as values in each row. So make sure you have all inputs, values, and extra columns properly described, before getting started here.
